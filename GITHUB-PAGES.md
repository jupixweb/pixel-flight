# Publicación en GitHub Pages

El juego se publica gratuitamente desde la rama main, carpeta raíz (/).
index.html abre el juego de dist/. .nojekyll permite servir los archivos directamente.

Para actualizarlo, sustituir dist/ con la versión nueva y mantener README.md y tests/ al día.
No se necesitan dependencias, claves, base de datos ni servicios de pago.

Las partidas y los desbloqueables se guardan en el navegador de cada jugador. GitHub Pages tiene su propio almacenamiento, separado de la dirección anterior.
